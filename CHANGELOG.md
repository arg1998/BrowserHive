# Changelog

Release notes are generated by [Changesets](https://github.com/changesets/changesets) when a version is released. Do not edit entries by hand; add a changeset instead (`bunx changeset`, see [.changeset/README.md](.changeset/README.md)).

The published package's changelog is written to `packages/browserhive/CHANGELOG.md` and mirrored on [GitHub Releases](https://github.com/browserhive/BrowserHive/releases).
