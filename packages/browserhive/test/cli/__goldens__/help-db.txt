browserhive db — Inspect, back up, restore, or migrate the database

USAGE
  browserhive db status [flags]
  browserhive db backup [flags]
  browserhive db restore <file> [flags]
  browserhive db migrate [flags]

Operates on <dataDir>/browserhive.db. restore refuses while a server is running on the data
directory.

COMMANDS
  status          Schema versions, application id, pending migrations, size, last backup, integrity
  backup          Write a consistent copy with VACUUM INTO
  restore <file>  Replace the database with a backup (the current file is backed up first)
  migrate         Apply pending migrations

FLAGS
  --dataDir <path>             Data directory (database, sessions, auth states, uploads, backups).
                               Defaults to the OS data dir. default: OS data directory
  --config <path>              Config file path. CLI and environment only: a config file cannot
                               point at another.
  --color <auto|always|never>  Colour for logs and CLI output. auto honours NO_COLOR, FORCE_COLOR,
                               TERM=dumb and TTY. default: auto

FLAGS — status
  --json  Print machine-readable JSON instead of text.

FLAGS — backup
  --out <path>  Backup file to write. default: <dataDir>/backups/browserhive-v<N>-<timestamp>.db

FLAGS — restore
  --yes  Skip the confirmation prompt.

FLAGS — migrate
  --dryRun  List pending migrations and apply nothing.
  --json    Print machine-readable JSON instead of text.

GLOBAL FLAGS
  -h, --help     Show help.
  -v, --version  Print the version.
