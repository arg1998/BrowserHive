browserhive sitepacks — List, review, approve and manage site packs

USAGE
  browserhive sitepacks list [flags]
  browserhive sitepacks show <pack> [flags]
  browserhive sitepacks check [flags]
  browserhive sitepacks download [pack] [version] [flags]
  browserhive sitepacks diff <pack> [flags]
  browserhive sitepacks apply <pack> [version] [flags]
  browserhive sitepacks reject <pack> [version] [flags]
  browserhive sitepacks revert <pack> [flags]
  browserhive sitepacks pin <pack> <version> [flags]
  browserhive sitepacks unpin <pack> [flags]
  browserhive sitepacks follow <pack> <setting> [flags]
  browserhive sitepacks approve-local <pack> [flags]
  browserhive sitepacks enable <pack> [flags]
  browserhive sitepacks disable <pack> [flags]
  browserhive sitepacks reload [flags]
  browserhive sitepacks import <path> [flags]
  browserhive sitepacks export <dir> [flags]
  browserhive sitepacks verify <path> [flags]

Talks to a running server over its REST API (--url, default the configured host and port) with an
operator bearer (--token) or the dashboard cookie (--cookie). A pack applies only once an operator
approved its version: adding a site to a template approves what it shows; later versions wait as
pending updates until you apply them. Registry versions are listed as available from the signed
index; download fetches and verifies one so you can review its diff. Local files in sitePacksDir
need approval once per content (SHA-256). apply, revert, approve-local and disable ask for
confirmation on a terminal and refuse without one unless --yes. check and list --pending exit 2 when
an update or a local file waits for you.

COMMANDS
  list                       List site packs with their approved version, local file and pending
                             updates
  show <pack>                Show a pack: approval, local file, classified pending versions, rules,
                             strategies
  check                      Check the online registry for new versions now (the signed index only)
  download [pack] [version]  Download & review: fetch a listed version, verify it, show its diff
  diff <pack>                Show the classified field changes from the approved version to a
                             candidate
  apply <pack> [version]     Approve a pending version: every template using the pack follows it
  reject <pack> [version]    Dismiss a pending version (a newer one appears again)
  revert <pack>              Go back to the previous approved version
  pin <pack> <version>       Keep a pack at its approved version; newer versions are listed, not
                             offered
  unpin <pack>               Stop pinning a pack
  follow <pack> <setting>    Choose whether a pack lists pending updates and notifies about them
  approve-local <pack>       Approve the local file's current content (prints its diff first)
  enable <pack>              Enable a disabled pack
  disable <pack>             Disable a pack: its sites become generic, its rules stop applying
  reload                     Read the bundled packs and the local folder (sitePacksDir) again
  import <path>              Import a signed registry layout, or one unsigned pack file, byte for
                             byte
  export <dir>               Write the server's verified signed layout to a folder, for an offline
                             host
  verify <path>              Check a site pack file or a signed registry layout offline

FLAGS
  --host <address>             Bind address. A non-loopback host requires auth=token or
                               allowInsecureBind=true. default: 127.0.0.1
  --port <1-65535>             Bind port for MCP, REST, WebSocket and the dashboard. default: 9876
  --config <path>              Config file path. CLI and environment only: a config file cannot
                               point at another.
  --color <auto|always|never>  Colour for logs and CLI output. auto honours NO_COLOR, FORCE_COLOR,
                               TERM=dumb and TTY. default: auto

FLAGS — list
  --source <local|registry|bundled|import>
                                    Only packs from these sources, comma-separated. default: every
                                    source
  --pending                         Only packs with a pending update or a local file waiting for
                                    approval. Exits 2 when there is one.
  --json                            Print machine-readable JSON instead of text.
  --url <url>                       The running server to talk to, over its REST API. default: the
                                    configured host and port, http://127.0.0.1:9876
  --token <bearer>                  Operator bearer token for --url (bh_operator_…).
  --cookie <value>                  Dashboard session cookie value for --url (browserhive_session).
