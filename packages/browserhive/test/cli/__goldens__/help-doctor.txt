browserhive doctor — Check the host, browsers, and configuration

USAGE
  browserhive doctor [flags]

Runs every host check and prints a table. Exit 0 when all checks pass, 1 when any fails, 2 for
warnings only. Accepts the server flags so the checks see the configuration serve would use.

FLAGS
  --json          Print machine-readable JSON instead of text.
  <server flags>  Every flag of 'browserhive serve' (see 'browserhive serve --help').

GLOBAL FLAGS
  -h, --help     Show help.
  -v, --version  Print the version.
