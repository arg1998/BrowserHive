browserhive admin — Administrative actions (reset-password, tokens)

USAGE
  browserhive admin reset-password [flags]
  browserhive admin tokens list [flags]
  browserhive admin tokens create <principal> [flags]
  browserhive admin tokens revoke <principal> [flags]

Works on the database directly and refuses while a server is running on the data directory; tokens
subcommands can instead talk to a running server with --url.

COMMANDS
  reset-password             Generate a new dashboard password (shown once)
  tokens list                List agent and operator bearer tokens
  tokens create <principal>  Issue a bearer token for a principal (plaintext shown once)
  tokens revoke <principal>  Revoke every active token of a principal (or one token's id)

FLAGS
  --dataDir <path>             Data directory (database, sessions, auth states, uploads, backups).
                               Defaults to the OS data dir. default: OS data directory
  --config <path>              Config file path. CLI and environment only: a config file cannot
                               point at another.
  --color <auto|always|never>  Colour for logs and CLI output. auto honours NO_COLOR, FORCE_COLOR,
                               TERM=dumb and TTY. default: auto

FLAGS — reset-password
  --json  Print machine-readable JSON instead of text.

FLAGS — tokens list
  --json            Print machine-readable JSON instead of text.
  --url <url>       Talk to a running server over its REST API instead of opening the database
                    (http://127.0.0.1:9876).
  --token <bearer>  Operator bearer token for --url (bh_operator_…).
  --cookie <value>  Dashboard session cookie value for --url (browserhive_session).

FLAGS — tokens create
  --json                  Print machine-readable JSON instead of text.
  --expiresIn <duration>  Token lifetime, e.g. 30d. Never expires when omitted.
  --url <url>             Talk to a running server over its REST API instead of opening the database
                          (http://127.0.0.1:9876).
  --token <bearer>        Operator bearer token for --url (bh_operator_…).
  --cookie <value>        Dashboard session cookie value for --url (browserhive_session).

FLAGS — tokens revoke
  --json            Print machine-readable JSON instead of text.
  --url <url>       Talk to a running server over its REST API instead of opening the database
                    (http://127.0.0.1:9876).
  --token <bearer>  Operator bearer token for --url (bh_operator_…).
  --cookie <value>  Dashboard session cookie value for --url (browserhive_session).

GLOBAL FLAGS
  -h, --help     Show help.
  -v, --version  Print the version.
