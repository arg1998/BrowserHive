browserhive templates login — Sign a template in to one of its sites again

USAGE
  browserhive templates login <name> [flags]

Talks to a running server over its REST API (--url, default the configured host and port) with an
operator bearer (--token) or the dashboard cookie (--cookie). create and login open a sign-in window
on the machine running the server, wherever the CLI runs, and wait until the sites are signed in,
you press Enter, or --timeout passes. create, finish, login and probe exit 0 when every site is
signed in, 2 when one is not, 1 on an API error. seed and restore run on the server and the CLI
waits for them. rekey is the exception: it runs locally against the data directory with the server
stopped.

ARGUMENTS
  <name>  Template name.

FLAGS
  --site <site>                The site to sign in to again (linkedin.com). Required.
  --method <window|vault>      window opens a sign-in window at the site on the machine running the
                               server; vault fills the site's linked vault login there, in the
                               background. default: window
  --timeout <duration>         How long to wait for the sign-in. The re-login is then cancelled.
                               default: 30m
  --letAgentsContinue          Do not pause the template's agents while the window is open. They may
                               then type into or navigate pages while you sign in.
  --json                       Print machine-readable JSON instead of text.
  --url <url>                  The running server to talk to, over its REST API. default: the
                               configured host and port, http://127.0.0.1:9876
  --token <bearer>             Operator bearer token for --url (bh_operator_…).
  --cookie <value>             Dashboard session cookie value for --url (browserhive_session).
  --host <address>             Bind address. A non-loopback host requires auth=token or
                               allowInsecureBind=true. default: 127.0.0.1
  --port <1-65535>             Bind port for MCP, REST, WebSocket and the dashboard. default: 9876
  --config <path>              Config file path. CLI and environment only: a config file cannot
                               point at another.
  --color <auto|always|never>  Colour for logs and CLI output. auto honours NO_COLOR, FORCE_COLOR,
                               TERM=dumb and TTY. default: auto

GLOBAL FLAGS
  -h, --help     Show help.
  -v, --version  Print the version.
